# Implicit prosody EEG experiment stimulus manipualtion #

This project belonged to the UTON grant, where I worked with it in the HUN-REN, Centre for Natural Sciences, Brain Imaging Centre

It's goal was to create a proper stimulus for our planned EEG experiment. One group of stimuli should have been the recorded spoken Hungarian sentences (one of them: "data/Herpay_Julia_eso_24.wav"), for the incoungrent condition. But, we needed incongruent versions of these sentences as well. We wanted to achieve this by manipulating pitch contour by mirroring it horizontally, thus effectively changing one major aspect prosody. We also had a plan to create a neutral condition by flattening the pitch contour.

These notebooks are the tests, and tryouts of different methods and packages.
