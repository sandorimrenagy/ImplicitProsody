# Implicit prosody EEG experiment stimulus manipualtion #

This project belonged to the UTON grant, where I worked with it in the HUN-REN, Centre for Natural Sciences, Brain Imaging Centre

It's goal was to create a proper stimulus for our planned EEG experiment. The stimuli should have been the recorded spoken Hungarian sentences (one of them: "data/Herpay_Julia_eso_24.wav"). But, we needed incongruent versions of these sentences by manipulating pitch contour, for example mirroring horizontally, thus effectively changing one aspect prosody.

These notebooks are the tests, and tryouts of different methods and packages.
